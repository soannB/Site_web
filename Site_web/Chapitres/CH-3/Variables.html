Les variables

Définition : Une variable est un objet symbolisé par un nom auquel on associe une valeur.

1. Types de base

En Python, Il existe 4 types de base :

  • Le type int (integer), qui définit un nombre entier

  • Le type float (flottant), qui définit les flottants (nombre à virgule)

  • Le type str (string), qui définit les chaines de caractères

  • Le type bool (booléens), qui définit un booléen

2. Affectation d'une valeur à une variable

Afin d'utiliser une variable, il faut toujours l'initialiser avec une valeur. On appelle cela une affectation. Voici comment affecter unne valeur à une variable :


variable = 3

  #Pour un integer


variable = 3.5

  #Pour un float


variable = "Coucou"

  #Pour une chaine de caractères


variable = True

  #Pour un booléen


Ainsi, nous avons le nom de la variable, un "=" (symbole d'affectation) et la valeur que l'on souhaite lui associer.

3. Manipulation des chaînes de caractères

Une chaîne de caractères, lors de son affectation à une variable, est toujours entourée par des guillemets simples ou doubles afin d'éviter au langage de la confondre avec une autre variable. Ainsi, si l'on écrit ...


variable = autre_variable


...la variable nommée "variable" prendra la valeur du contenu de la variable "autre_variable".

Reconcentrons-nous sur les chaînes de caractères.

Il est possible d'assembler deux chaines de caractères ensemble. Ce faisant, on réalise une concaténation. Voici comment réaliser une concaténation :


variable = "a"+"b"

  #La variable contiendra "ab"


Il est tout à fait possible de réaliser une concaténation avec deux variables (à condition qu'elles soient de type str) :


variable = var1 + var2


Afin d'afficher des messages, des valeurs ou des contenus de variable, on peut utiliser la fonction print(). Attention cependant, cette fonction ne permet que de l'affichage.


var1 = "Coucou"

 


var2 = "l'ekip"

 


variable = var1 + var2

 


>>> print(variable)

 


>>> Coucou l'ekip

  #Les ">>>" correspondent à l'utilisation de Python en mode interactif
