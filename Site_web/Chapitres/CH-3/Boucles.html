Les boucles

Les boucles permettent de répéter "automatiquement" des actions sans avoir à écrire plusieurs fois la même action.

1. La boucle for

En Python (et dans d'autres langages par ailleurs), la boucle for est une structure permettant de répéter une ou plusieurs actions un nombre de fois défini. La boucle a toujours le même format :


for i in range(x):

 


    print("Ouesh l'ekip")

 


    ...

 

#Avec i la variable de boucle et x le nombre de répétitions
