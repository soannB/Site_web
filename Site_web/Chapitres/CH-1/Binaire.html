Le binaire

Definition : Le binaire est un langage composé de deux nombres : 0 et 1. Ces deux nombres sont appelés "bits de données".
      On associe ces bits de données pour former des chiffres binaires.

1. De décimale à binaire

Pour faire passer un chiffre décimale en binaire, on fait des divisions euclidiennes succesives par 2.
 On a alors 2 cas possible :

  •  Le reste est à 0.

 Au quel cas le chiffre correspondent est 0

  •  Le reste n'est pas à 0.

 Au quel cas le chiffre correspondent est 1

Ex:
17 / 2 = 8 : 1

8 / 2 = 4 : 0

4 / 2 = 2 : 0

2 / 2 = 1 : 0

1 / 2 = 0 : 1

2. De binaire à décimale

Pour faire passer un chiffre binaire en décimale, il faut reflechir en puissance de 2, de droite à gauche.

 Ex : 100101(2) → 25 + 22 + 20 = 32 + 4 + 1 = 37(10)
